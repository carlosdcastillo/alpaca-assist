Status Bar Improvements

Overview

The status bar has been enhanced to display whether the current tab is running locally or as a Pack (remote) connection. For Pack tabs, it now shows the remote host name and connection status.

New Features

  • Local Badge: Displays "Local" for tabs running on this machine
  • Pack Badge: Shows "Pack: [hostname]" for remote connections
  • Connection Status: Visual indicator for connected (green) vs disconnected (red) Pack tabs
  • Real-time Updates: Badge updates automatically when connection state changes
  • Existing Chat Data: All previous status bar information (chat stats, tokens, streaming state) remains unchanged

Technical Implementation

Backend Changes (Python)

The get_status_info() method in webview_api.py now returns additional fields:

  • is_pack: Boolean indicating if the tab is a Pack tab
  • host: The remote hostname (for Pack tabs only)
  • connected: Boolean indicating connection status (for Pack tabs only)
  • session_id: The Pack session ID (for Pack tabs only)

Frontend Changes (JavaScript)

A new _updateConnectionBadge() method in app.js:

  • Creates and manages a badge element in the status bar
  • Updates badge text and styling based on tab type and connection state
  • Called automatically when the status bar updates
  • Responds to Pack connection events (errors, state syncs)

Styling (CSS)

New CSS classes in app.css:

  • .status-connection: Base badge styling
  • .status-connection--local: Gray badge for local tabs
  • .status-connection--connected: Green badge for connected Pack tabs
  • .status-connection--disconnected: Red badge for disconnected Pack tabs
Note: The badge updates in real-time when Pack connections are lost or restored, ensuring users always know the current connection state.

Testing

New unit tests in tests/test_webview_api_status_info.py verify:

  • Local tabs return is_pack: false
  • Pack tabs return correct host and connection status
  • Disconnected Pack tabs are properly identified
  • Chat statistics remain accurate for both tab types

All 663 existing tests continue to pass.
